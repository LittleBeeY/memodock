# Security Policy

## Supported Versions

| Version | Support |
|---------|---------|
| 0.3.x | ✅ Actively supported |
| < 0.3 | ❌ Not supported |

## Data & Privacy Stance

MemoDock is a local-first application: records stay on this machine, no network service is required, and no telemetry is collected. **Data is stored as plaintext JSON, which is not the same as encrypted storage.**

## Reporting a Vulnerability

Please **do not** report security vulnerabilities in a public Issue. Contact the maintainer through a private channel instead:

- Open a private vulnerability report (GitHub Security Advisory) labeled `security`
- Send an email to: 483074131@qq.com

Please include:

- Affected version and operating system
- Reproduction steps (keep them concise)
- Impact description (which data/behavior is affected)

We will respond and follow up promptly. The issue will only be disclosed publicly after a fix is released.
